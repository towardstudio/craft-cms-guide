The website's menus are managed in **Navigation**, in the main menu on the left.

## Edit a menu

1. Go to **Navigation** and choose the menu you want to change.
2. Add an item by choosing the type of link you want to add from the options on the right of the screen. This can vary by website. Usual options are **Entry**, **Asset** or **Custom URL**.
3. Drag items to reorder them. Drag an item under another to make it part of a dropdown, if the menu is set up to support this.
4. Save your changes.

When you link to an entry, the menu uses the entry's current title and address, so it stays correct if the page changes. You can give the menu item a shorter title if you need to.

If you want to temporarily disable a navigation item, click the checkbox next to it. A **Set Status** menu will appear at the top of the screen. Choose the **Disabled** option from this menu and then save your changes.
