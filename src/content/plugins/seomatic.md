The website uses the SEOmatic plugin to automatically set the title, description and image that search engines and social networks show for each page.

## Change them for invididual pages

Whilst the website will automatically use default values for the title, description and image, entries that have an SEO tab contain fields that let you override those defaults for that page only.

- **Title**: what shows as the link in search results. Keep it short and specific to the page.
- **Description**: the short summary under the link in search results. We recommend you write a different one for each page, in one or two sentences.
- **Image**: the image shown when someone shares the page on social media.

Search engines decide what to show, so they won't always use exactly what you enter.

## Preview

The SEOmatic plugin also provides a preview of what the page looks like in Google search results as well as when it's shared on X or Facebook. These previews are displayed in the right-hand sidebar when editing a page entry and also under the X (Twitter) and Facebook tabs under the SEO tab.
