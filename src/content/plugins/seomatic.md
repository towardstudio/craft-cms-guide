The website sets the title, description and image that search engines and social networks show for each page. These are filled in automatically from the page's content.

## Change them for one page

Entries that have an SEO field let you replace the automatic title, description or image for that page only.

- **Title**: what shows as the link in search results. Keep it short and specific to the page.
- **Description**: the short summary under the link in search results. Write a different one for each page, in one or two sentences.
- **Image**: the image shown when someone shares the page on social media.

Search engines decide what to show, so they won't always use exactly what you enter.
