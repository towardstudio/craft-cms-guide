Link fields are used for buttons and calls to action. First choose the type of link, then choose or enter where it goes.

## Types of link

- **Entry**: a page on this website. Choose this whenever you can. If the page's address changes later, the link updates automatically.
- **URL**: a full web address, such as a page on another website. Include `https://`.
- **Asset**: a file in Assets, such as a PDF.
- **Email**: opens the visitor's email app with your address filled in.
- **Phone**: lets visitors on a phone call the number.

The types you see depend on how each field is set up.

## Link text

Some link fields let you set the text shown on the button. Make it describe where the link goes, for example "Read our annual report" rather than "Click here".
