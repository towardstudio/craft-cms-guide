## Drafts

A draft lets you work on changes to an entry over time, or share them for review, without changing the live page.

- Create a draft from the edit screen of the entry you want to change.
- Save the draft as often as you like. The live page doesn't change.
- When the draft is ready, apply it to make the changes live.

You can use **Preview** with a draft to see how the page will look.

## Revisions

Every time an entry is saved, the CMS keeps a copy of the previous version. If something goes wrong, you can go back to an earlier version.

1. Open the entry.
2. Open the revisions menu near the entry's title at the top of the screen.
3. Choose the version you want to look at.
4. If it's the one you need, choose to revert to it.

Reverting replaces the current content with the earlier version. The current version is kept as a revision too, so you can undo this if needed.
