Images, documents and other files are stored in **Assets**. When a field asks for an image or file, you can choose one already in Assets or upload a new one.

## Upload a file

- In **Assets**, drag files from your computer onto the window, or use the upload button.
- In an image or file field, select the button under the field, then upload or choose a file.

## Before you upload

- **Name files clearly.** For example, `team-photo-2026.jpg` rather than `IMG_4032.jpg`. File names can show up in search results.
- **Resize large photos.** Photos straight from a camera or phone are often much larger than needed and slow the website down. The website creates the sizes it needs from the image you upload, so there's no need to upload very large originals.
- **Check the format.** Use JPG for photos, PNG for graphics with sharp edges and SVG for logos and icons where the field asks for it.

## Alternative text

Alternative (alt) text describes an image for people who can't see it, including people using screen readers. Search engines use it too.

Whenever you upload an image, you should double-click on it and then fill out the 'Alternative Text' field for it.

- Describe what the image shows and why it matters on the page.
- Keep it short, usually a sentence.
- Don't start with "Image of".
- Leave it blank only if the image is purely decorative.

## Focus point and cropping

The website crops images to fit different spaces and screen sizes. To stop the important part being cut off, open the image in Assets, edit it and set its focal point. The website keeps that point in view when it crops the image.
