Some fields let you build content from a series of blocks. Each block is a different type of content, such as a heading with text, an image, or a grid of cards. You choose which blocks to use and what order they go in.

[See the content blocks on {{ siteName }}]({{ guideUrl }}).

## Add a block

Select the button under the field (for example **Add Content Block**), then choose the type of block you want. Fill in its fields.

## Edit a block

Depending on how the field is set up, blocks appear in one of two ways:

- **As cards**: each block is shown as a card. Select a card to open it and edit its fields.
- **Inline**: each block's fields are shown directly on the page.

## Reorder, hide or delete a block

Each block has an actions menu. Use it to:

- move the block up or down
- disable the block, which hides it from the website without deleting it
- delete the block

You can also drag blocks into a new order by clicking on the '4 dots' icon on the block and dragging the block into the relevant position.

## Blocks inside blocks

Some blocks contain their own list of items, such as the cards in a grid. These work the same way as the blocks on the page.

Changes to blocks are saved when you save the entry they belong to.
