## Add an entry

1. Go to **Entries** and choose a section from the list on the left.
2. Select **New entry**.
3. Fill in the fields. Fields marked as required must be filled in before you can save.
4. Select **Save**.

## Edit an entry

Go to **Entries**, find the entry and select its title.

While you edit, the CMS keeps your changes as you go, but **they are not live on the website until you select Save**. If you leave and come back, your unsaved changes are still there. You can throw them away if you change your mind.

You can also save with <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows) or <kbd>⌘</kbd> + <kbd>S</kbd> (Mac).

## Preview before saving

Select **Preview** to see how the entry will look on the website while you edit it. Preview only works for entries that have their own page.

## Control when an entry is live

The panel on the right of the edit screen has settings for the entry as a whole.

- **Enabled**: turn this off to hide the entry from the website without deleting it.
- **Post date**: the entry won't appear on the website until this date and time.
- **Expiry date**: the entry is hidden from the website after this date and time. Leave it blank to keep it live.
- **Slug**: the part of the web address that identifies this entry. Changing it changes the page's address. {% if autoRedirects %}The website automatically redirects the old address to the new one, so existing links keep working.{% else %}Links to the old address will stop working, so only change it if you need to.{% endif %}

## Tabs

Some entries have their fields split across tabs at the top of the edit screen. Check each tab before you save.
