# Changelog

## 1.0.0 - Unreleased

### Added
- Guide built into the control panel, visible to anyone with the "Access CMS Guide" permission.
- Generic pages on using Craft: logging in, finding your way around, editing entries, drafts and revisions, content blocks, images and files, links and buttons, formatting text.
- Generic pages for Freeform, Navigation, Retour and SEOmatic, shown only when that plugin is installed.
- Section and content block pages built from the site's sections, entry types and field instructions, in the same order as the Entries sidebar.
- Site-specific content from the site's `cms-guide` folder: intro, section notes, block notes and example images, plugin notes and extra pages.
- Public `/cms-guide` address that sends people to the guide via the login page.
- Images in guide content, served only to logged-in users.
- `vendor/bin/cms-guide-images` for converting screenshots to WebP.
